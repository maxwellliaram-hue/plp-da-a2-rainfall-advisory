# Rainfall Analysis and Planting Advisory

- This project cleans and analyzes monthly rainfall data across five counties to identify reliable planting windows and potential rainfall risks.
- Open rainfall_analysis.ipynb in Jupyter or VS Code and run all cells from top to bottom with Python and NumPy installed.
- The strongest planting windows fall around the wettest consecutive months for each county, while the Machakos record should be treated as a cleaned estimate because it included handwritten errors.
